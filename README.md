# @ankhorage/zora-game

Generic game presentation primitives for React Native and React Native Web apps built on ZORA.

> This repository is being bootstrapped. Release documentation is generated by Paradox from source documentation and examples.

## Scope

`@ankhorage/zora-game` owns generic game presentation primitives and React Native / React Native Web presentation adapters. Game semantics and session behavior belong to `@ankhorage/game`.
